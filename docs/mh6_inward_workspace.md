# 从伸开位进入闭合侧的条件工作空间

默认配置 `mh6_palm_adapter_neutral_to_grasp.json` 使用 `mapping_mode=workspace_conditional`、
`workspace_profile=closing_only`。手掌三分量仍为 `[0,1]`，参数顺序为 `(h,r,v)`。
人手标定、意图权重、五指/M4 映射、绝对限位和位置跳变阈值均未因本次改动而调整。

## 工作空间与电机标定

原 Solver 的三条换算在硬件 ID 顺序下为：

| 电机 | 标定公式 | 伸开到闭合 | 对应机构角范围 |
|---|---|---|---|
| M1 | `247 - 753/180 * alpha3` | 247 → 1000 | alpha3: −180°～0° |
| M2 | `500 - 380/90.8 * alpha2` | 500 → 120 | alpha2: 0°～90.8° |
| M3 | `500 + 99/23.6 * alpha1` | 500 → 401 | alpha1: −23.6°～0° |

零意图先生成机构角 `[alpha2,alpha3,theta1]=[0,0,0]`，再由原 Solver 计算出
`[247,500,500]`。原生归一化 API 的零输入不是平面零位，因此新 profile 不直接调用该 API。
它先生成受约束的角度，然后调用同一个 `solve_motor_safe()`；原 Solver 两份源码保持逐字节一致。

生成过程为：

1. `alpha2 = 90.8*h`；若硬件限位更窄，按相同 Solver 标定式收缩角度上限。
2. 给定 alpha2 与拇指分量 r，计算从零开始、plus 分支仍处于闭合侧的左右翻折容量。
   容量受 theta1 原输入范围、alpha1 闭合范围以及 alpha3 电机范围共同限制。
   容量止于 alpha1 第一次向内弯曲的极值或先遇到的电机边界；用一维极值搜索与二分定位，
   不跨过反向弯曲段或不可行孔洞。对侧分支不能用来填补当前分支的不可行点。
3. `theta1 = -容量*v`。调用 Solver 的解析几何可行区间，在负 alpha3 区间内按
   `sin(pi*r/2)` 取值，平滑接近 r=1 的几何端点；r 的输入值和意图权重不变。
   非零几何端点向内缩入相对区间的 1e-6，避免落在另一个分支合并边界上；零输入保留精确平面位。
4. 原 Solver 求解完整三元组；适配层只将符合电机范围的 plus 解列为有效 solutions。
   另一个解析解保留在 candidates 中用于诊断，不作为允许的向内分支。
5. 控制层继续取整并执行原位置跳变保护；M1～M3 整组接受或保持，不裁剪单个电机值。

伸开位是两个解析分支的合并点，该唯一姿态归属连续的 plus 装配分支。
接近伸开位时两支若在 Solver 四位小数控制值精度下相同，也允许识别为同一个 plus 电机命令。
其他情况下仍按照解析根而非列表索引识别分支。

**条件映射保留机构耦合：**h=0 时，在本闭合侧参数化中拇指/左右翻折轴会退化，
输出仍为伸开位；v=0 时可用 alpha3 区间也可能退化。因此输入为正不保证每台电机都有明显运动。
日志 `workspace_diagnostic` 保存翻折容量、退化轴和分支合并标记。
电机各自允许的行程端点也不意味着三个端点能同时满足闭环。
